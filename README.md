## 📊 Book Sales Performance Analysis (Excel)

This project demonstrates how Excel can be used to organize and analyze structured sales data to support business decision-making.

### Tools Used
- Microsoft Excel  
- Pivot Tables  
- Multi-sheet data integration  

### Key Features
- Organized structured dataset  
- Built pivot table to summarize sales performance  
- Calculated totals and royalties  
- Integrated multiple worksheets for reporting  

### Business Value
Shows how data can be transformed into insights for:
- Revenue tracking  
- Performance monitoring  
- Decision support
